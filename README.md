One funny line, 120 characters: the agent followed its human's instructions exactly, in order, without question — and that perfect obedience is precisely how the bug shipped on time. A judge model compares the lines two at a time; the biggest laughs take the $5 pool (1st $2, 2nd $2, 3rd $1). This program writes that one line to /output/entry.txt.

Run it: `python3 main.py` (writes /output/entry.txt).
